# SCENE-AI：基于多模态感知的智能场景触发式移动助手系统（Android + 云端）

## 项目简介
SCENE-AI 是一款运行在 Android 手机上的“场景触发式 AI 助手”，通过实时感知用户所处场景（摄像头 / 当前 App / 时间 / 位置等），在最合适的时刻主动提供 AI 服务，实现“无需唤醒、无需搜索”的随身智能体验。项目定位为：生活场景优先，而非学习工具。

---

## 一、整体系统架构

### Android 端：
系统状态 / 摄像头 / 位置 / 当前App  
        ↓  
场景判断模块（本地）  
        ↓  
场景调度器  
        ↓  
请求云端 AI 服务  
        ↓  
结果解析  
        ↓  
浮窗 / 页面展示  

### 云端：
FastAPI API  
↓  
多模态模型 / LLM  
↓  
结构化结果（JSON）  

---

## 二、技术选型

### Android：
- 摄像头：CameraX / 系统相机
- 网络通信：OkHttp
- UI：Activity / Dialog / 悬浮窗
- 场景检测：Accessibility Service
- 定位：FusedLocationProvider / Geocoder
- 后台：WorkManager
- 权限：CAMERA / INTERNET / LOCATION / SYSTEM_ALERT_WINDOW

### 云端：
- API 框架：FastAPI
- 图像处理：Pillow / OpenCV
- OCR（可选）
- 多模态模型 API
- 大语言模型 API
- 异步：asyncio
- 部署：Docker / 云服务器

## 三、功能模块（生活场景为核心）

### 🍜 做饭 / 饮食场景
- 功能：拍食材识别、推荐做法、健康建议
- AI：多模态模型 + 大语言模型

### 💬 聊天辅助
- 功能：生成一句话回复、润色语气、总结长消息
- AI：大语言模型
- 触发：当前 App 为微信 / QQ

### 📄 阅读场景
- 功能：网页 / PDF 总结与问答
- AI：大语言模型 + 可选 OCR / 视觉模型

### 📍 位置感知服务
- 功能：根据当前位置（超市 / 商场 / 校园）提供生活提示
- AI：可选（规则为主，可调用 LLM 优化建议）

### 🌙 夜间 / 护眼模式
- 功能：夜间自动降低亮度、提醒休息
- AI：不需要（系统控制）

## 五、UI 设计（助手型 App 模板）

### 首页（控制面板）
- 功能开关：做饭 / 聊天 / 阅读 / 护眼
- 状态显示：运行中 / 已停止
- 手动测试按钮

### 结果展示页 / 悬浮窗
- 当前场景
- 识别结果
- 建议
- 按钮：复制 / 关闭

### 交互原则
- AI 主动出现
- 打扰最小化
- 支持一键关闭

## 九、结语

SCENE-AI 不是一个简单功能集合，而是一次对“手机如何成为随身 AI 助手”的探索。
